📋 系统概述

本系统用于高露洁扬州工厂 Koch 包装机产线，对牙膏盒进行全自动视觉检测。

项目说明
检测对象牙膏包装盒（每排 P 盒，Z 排）
检测工位正面、背面、上端面、下端面、左侧面、右侧面 — 共 6 面
检测项盒子破损、P号码OCR、条码识别、日期码识别、挂钩错位、端面缺陷、侧面缺陷
相机8 台大华工业相机（每工位 2 台，左右视角）
运动控制ZMC 运动控制卡（侧面工位运动轴）
AI引擎YOLO ONNX（目标检测）+ SmartMore ViMo（OCR/分割/分类）
PLC西门子 S7-1500（Modbus TCP 通讯）
GPUGPU0: 盒子破+条码+挂钩(4个YOLO) | GPU1: 端面x2+侧面+OCR(4个YOLO+3个ViMo)

📊 数据流向

阶段数据流路径
1. 传感器→触发IN4/IN10/IN12/IN13 → CameraTriggerManager.MonitorLoop(2000Hz) → 边沿检测 → PulseOutputLoop → OUT8~OUT15 脉冲 → 相机拍照
2. 相机→图像DaHuaSDK.OnImage 事件(Camera1~8) → MainFrm.OnCameraNImage → 分发到各工位处理器
3. 工位→推理Front: 配对→并行推理(P号+破损)→汇总 | Back: 配对→3路并行推理(条码+日期+挂钩) | EndFace: 队列收集P张→批次YOLO | Side: 运动轴前进+实时推理
4. 结果→显示ProductResult → MainFrm.OnStationResult → PictureBox(xlPictureBox1~6) + OK/NG标签 + 良率
5. 结果→保存各工位SaveImages → HighSpeedImageSaver后台队列 → JPEG 85%质量 → Images/{日期}/{班次}/{工位}/{OK|NG}/
6. 结果→PLCPlcCommunication.SendResult (桩代码, 未实际实现)

📷 正面工位 — FrontStationProcessor

项目说明
相机Camera1(正面左) + Camera2(正面右)
触发IN4 上升沿 (与背面共享) / OUT9 + OUT8
检测项P号码OCR(ViMo) + 盒子破损(YOLO)
处理配对模式: 左右图都到达→Flip→裁图→2路并行推理→汇总
显示xlPictureBox1
📝 处理流程 (CheckAndProcessAsync)
0. 左右图配对: _leftBuffer != null && _rightBuffer != null
1. Flip(XY翻转): Cv2.Flip 纠正镜像
2. 裁图: 根据SKU配置的裁图坐标裁剪
3. 并行推理:
   ├─ Task.Run → RecognizePNumber (逐盒ROI→ViMo OCR→比对标准P号)
   └─ Task.Run → DetectBoxDamage (YOLO→ProcessYoloResults→分盒映射)
4. 汇总: 逐盒合并P号结果+破损结果 → statusList
5. 统计: P=全部 OK/NG (单盒粒度)
6. 日志: O/X网格 + 缺陷统计 + 耗时
🔧 可调参数
参数默认值调整位置
ConfThreshold0.25检测参数→正面Tab / ModelParams/front_box.json
EnableBoxBreakChecktrue检测参数→正面Tab
EnablePNumberCheckfalse检测参数→正面Tab

🔍 背面工位 — BackStationProcessor

项目说明
相机Camera5(背面左, OnCam3) + Camera6(背面右, OnCam4)
触发IN4 上升沿 / OUT12+OUT13
检测项条码(ZXing) + 日期码(C1+C2+C3) + 挂钩(YOLO+分割厚度)
处理配对模式→3路并行推理→汇总
显示xlPictureBox2
📝 核心检测流程
1. 条码: 逐盒ROI→ApplyBarcodePreprocess(对比度/直方图/阈值/形态学)
   → ZXing BarcodeReader.DecodeMultiple → 与参考条码比对
   ★ 预处理管线: 对比度→直方图均衡→高斯→中值→自适应阈值→形态学
2. 日期码(C1+C2+C3):
   C1: ViMo分割模型→Mask→ConnectedComponents提取区域
   C2: ViMo分类模型→判断重影(NG=重影, OK=正常)
   C3: ViMo OCR→识别文本→格式校验(MFG/LOT/双排)→日期比对
3. 挂钩:
   YOLO检测: classId=1→明显错位(DarkRed)
              classId=0→分割→DistanceTransform→maxVal*2=厚度
              厚度>HookThicknessThreshold→轻微错位(OrangeRed)

参数默认值调整位置

📐 端面工位 — EndFaceStationProcessor

项目说明
相机Camera3(上端面) + Camera4(下端面)
触发IN10 上升沿 / OUT10 + OUT11
检测项上端面缺陷(破损/搭舌/边缘) + 下端面缺陷 — YOLO检测
处理模式批次模式: ConcurrentQueue收集P张→BlockingCollection→ProcessBatch并行YOLO
防呆超时5秒未满P张→强制处理现有图+清空残留
线程独立后台线程 ProcessLoop(AboveNormal优先级)
显示xlPictureBox3(上端面) + xlPictureBox4(下端面)
📝 批处理流程
1. EnqueueImage: ConcurrentQueue原子入队→上下各P张触发
2. BlockingCollection.Add批次→ProcessLoop消费
3. ProcessBatch: 裁图(上裁右/下裁左)→并行YOLO(上下各自推理)
   →ParseResults→汇总(upperStatus && lowerStatus→mergedStatus)
4. 显示: 独立索引(upperIndex/lowerIndex), NG优先, 全OK最后一张
5. 保存: 渲染图+原图→Images/{日期}/{班次}/端面工位/{上下}/{OK|NG}/

⚙️ 侧面工位 — SideStationProcessor 最复杂

项目说明
相机Camera7(左侧面) + Camera8(右侧面)
触发IN13 ↑→Cam7(预归位) / IN13 ↓→Cam8(启动检测)
检测项侧面缺陷(头尾裁剪YOLO推理) — 每图裁头尾两段→批量推理→坐标映射
运动轴ZMC轴: 起点→终点(ForwardSpeed)→起点(ReturnSpeed), 参数在AxisParams.json
推理模式实时流式: 运动中拍一张→推理一张→OnRealTimeDisplay推送UI
安全锁IN8 双层防护: 硬件ALM_IN(CPU100%有效) + 软件5ms轮询, 支持继续/返回两种恢复模式
显示xlPictureBox5(左侧面) + xlPictureBox6(右侧面)
📝 完整检测流程 (StartDetection)
1. 安全锁等待: CheckSafetyLock()→门关(IN8=1)才继续
2. ClearBatch()→清空队列+结果
3. 并行启动:
   ├─ ProcessStream: 交替取左右图→InferSingle→实时显示
   └─ StartMotion: 起点→终点(ForwardSpeed)→起点(ReturnSpeed)
      ★ WaitForMove每5ms安全锁轮询:
        门开→EmergencyStop(mode=0)→等待恢复→
         Continue: ClearHardwareAlarm+MoveAbs(目标)
         ReturnToStart: ClearHardwareAlarm+MoveAbs(起点)→中止
4. FinalizeResults: 填充缺失→合并左右→汇总OK/NG→保存+显示

⚡ 触发管理器 — CameraTriggerManager

3线程架构 + CPU核心绑定:

线程优先级职责
MonitorLoopHighest绑定最后CPU核心, 2000Hz扫描IN4~IN13, GetInMulti(4,13)批量读→位运算边沿检测
PulseOutputLoopAboveNormal消费脉冲队列, 批量位掩码输出(SetOutMulti), SpinWait精确延时
StatsReportLoopNormal每15秒输出触发统计表(空闲时跳过不打印)
★ 外部触发模式: ExternalTriggerEnabled = true 时，所有OUT脉冲由ZMC BASIC程序控制。此时只监听IN13启动侧面工位。此模式下 MainFrm 会启动心跳(每150ms写ZMC变量HeartBeat_Flag)。

🛡️ 安全锁 — 双层防护架构

IN8 (门开关, 关门=1/开门=0)
    │
    ├─→ 硬件层: ZAux_Direct_SetAlmIn(handle, axis, port)
    │   ZMC控制器硬件级报警输入
    │   门开 → 控制器自身急停 (0.1ms级响应)
    │   ★ CPU 100% 时仍然有效
    │
    └─→ 软件层: CheckSafetyLock() 每5ms轮询
        门开 → EmergencyStop(axis, mode=0 立即停)
        门关 → ClearHardwareAlarm + MoveAbs
               恢复模式:
               0=Continue(继续执行到原目标)
               1=ReturnToStart(返回起始位并中止)
覆盖范围: 所有运动轴代码路径全部覆盖—SideStationProcessor.StartMotion/WaitForMove、MainFrm.OnCameraTriggered预归位、ControlFrm所有手动/自动运动按钮。
